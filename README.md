# Yanoka Job Radar

Personal job-search radar for fresh, relevant openings.

This project is based on [ScottCoffin/Job_Scraper](https://github.com/ScottCoffin/Job_Scraper), licensed under the GNU Affero General Public License v3.0.

Customized on 2026-09-29 for two search tracks:
- Flexible side work: AI evaluation/training, CAD/engineering, computational biology expert work.
- Career roles: biotech/lab/clinical/sample-processing/QC/R&D/automation roles in the California East Bay area.

The radar prioritizes fresh postings and keeps unknown-date jobs distinct from verified recent listings.
